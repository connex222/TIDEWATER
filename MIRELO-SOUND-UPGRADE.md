# TIDEWATER — Installed Mirelo recordings (v0.13.1)

The eight original Mirelo SFX 2.0 recordings were uploaded by the game owner on 24 October 2026 in `TIDEWATER-MIRELO-AUDIO.zip`, verified as valid 48 kHz mono PCM WAV files, and **installed** into this build. Each recording has a 48 kHz WAV master in `public/audio/mirelo-masters/` and normalised MP3 and Ogg versions in `public/audio/`.

| Cue | Sound | WAV duration |
|---|---|---|
| `bell` | Brass ship's bell | 2.0 seconds |
| `cannon` | Naval cannon | 3.0 seconds |
| `deal` | Trading notification | 1.9 seconds |
| `market` | Market movement | 1.7 seconds |
| `build` | Harbour construction | 2.4 seconds |
| `tide` | Tide change | 2.8 seconds |
| `victory` | Victory celebration | 3.8 seconds |
| `warning` | Warning / pause | 1.7 seconds |

The files under `public/audio/mirelo-assets.json` identify all 24 assets and their SHA256 hashes, durations and source. Music retains its original locally bundled composition and has not been regenerated by Mirelo.

All player sounds are optional; the TV has a dedicated effects toggle and volume and the phone uses optional effects. The game loads only bundled same-origin `/audio/*.mp3` files at runtime. No external audio service or signed production URL is required.

The previous procedurally synthesised sound effects are retained in the downloadable release archive under `public/audio/previous-synthetic`. As Git history also preserves previous audio, the on-server deployment need not serve duplicate originals.

To verify the installed premium effects in a development checkout: `python tools/verify_mirelo_installation.py`. This check needs Python 3 and FFprobe. The 48 kHz masters must be present. Run `npm test` for the SHA256 asset verification and full game tests.
